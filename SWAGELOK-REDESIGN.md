# Rediseño visual Swagelok Perú

Esta versión conserva la lógica original de Plan & Prueba y actualiza la identidad visual para alinearla con una herramienta técnica corporativa de Swagelok Perú.

Cambios principales:
- Navegación azul corporativa con acento rojo.
- Encabezado y jerarquía visual más técnica.
- Formularios, tarjetas, estados y vista previa unificados.
- PDF actualizado a la nueva línea visual.
- Responsive conservado.
- Base de Vite configurada para `/Plan-y-Prueba/` en GitHub Pages.

Validación: `npm test` ejecutado con 6/6 pruebas aprobadas.
